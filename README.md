# CodeAlpha Web Scraping

## 📌 Project Overview

## 📌 Project Overview

This project is part of the Data Analytics tasks assigned by **CodeAlpha**.
It focuses on web scraping, data cleaning, and visualization using Python.
The project uses Python to scrape book-related data from a website, clean the collected data, save it into a CSV file, and visualize the results using a chart.

## 🛠️ Technologies Used

* Python
* BeautifulSoup
* Requests
* Pandas
* Matplotlib
* Jupyter Notebook

## 📂 Project Files

* `CodeAlpha_Web_Scraping.ipynb` — Complete web scraping, data cleaning, and visualization notebook
* `books_scraped.csv` — Scraped and cleaned book dataset
* `README.md` — Project documentation

## 🔎 Web Scraping

The project collects book information from a website using Python and web scraping techniques.

The scraped data is processed and organized into a structured dataset using Pandas.

## 🧹 Data Cleaning

The collected book data was cleaned and prepared for analysis before saving it as a CSV file.

## 📊 Books Chart

The scraped book data was visualized using a **Books Chart** to make the collected information easier to understand.
